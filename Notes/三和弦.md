# 1. 三和弦

三和弦的原位是根音，距离根音三度，距离根音五度的音构成的。三和弦以根音命名，后面不加，加上m，加上$^{\circ}$，加上+，加上Sus2，加上Sus4，分别表示，大三，小三，减三，增三，挂二，挂四和弦。这四种的判断根据下表：

# 2. 转位和弦

给定和弦，先去掉重复，判断是什么和弦，以及这个和弦的根音。将最低的音定义为底音。注意底音不一定是根音。根据底音是什么可以判断和弦是什么转位。

Slash notation：可以用这个notation标记和弦以及其底音。例如C/E表示C大三和弦，且底音为E。
