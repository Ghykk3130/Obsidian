# 1. 三和弦

三和弦的原位是根音，距离根音三度，距离根音五度的音构成的。三和弦以根音命名，后面不加，加上m，加上$^{\circ}$，加上+，加上Sus2，加上Sus4，分别表示，大三，小三，减三，增三，挂二，挂四和弦。这四种的判断根据下表：

# 2. 转位和弦

给定和弦，先去掉重复，判断是什么和弦，以及这个和弦的根音。将最低的音定义为底音。注意底音不一定是根音。根据底音是什么可以判断和弦是什么转位。

Slash notation：可以用这个notation标记和弦以及其底音。例如C/E表示C大三和弦，且底音为E。

# 3. 如何快速判断三和弦

对于只有三个音的三和弦，容易发现原位是三个音在一起。第一转位是两个音黏在一起在下面，一个音在上面。第二转位是两个音黏在一起在上面，一个音在下面。转位的根音都是上面部分的最下面一个音。例如第一转位上面部分最下面一个音就是C。第二转位上面部分最下面一个音还是C。
![[Pasted image 20260818232257.png|centering|300]]
如果这些音没有黏在一起的部分，尝试把它们全部平移到一个八度内。例如底音声部平移到高音声部只需要整体网上抬一格。然后再看什么部分是黏在一起的。
