


# 1. 和弦进行

- 在自然大调中，可以构建七个三和弦，C, Dm, Em, F, G, A, B$^{\circ}$。
- 以四级音为root构成的和弦被称为下属和弦。以五级音为root构成的和弦被称为属和弦。下属和弦能制造离开主和弦的倾向，往往用于展开。属和弦有在五度圈上回到主和弦的倾向，常用于结尾式。
- 除此之外，别的和弦也有近似的听感。例如Am具有主功能。Dm具有属功能。
- 和弦进行以主功能和弦开头，所以一般就是C或者Am开头。Am比C更忧郁一点。

Ex: 
- 1625进行。即C-Am-Dm-G。从C进行到Am相当于从自然大调转向自然小调，带有忧郁色彩。同时C和Am的两个音都是一样的，不至于有太多差异。所以Am同样带有主和弦的味道，只不过更加忧郁。同时注意到，Am-Dm-G是一个五度圈下行的进行。沿着五度圈进行通常具有推动力。同时，Dm具有下属功能，所以Dm-G的进行非常自然，有着最后回到C的倾向。所以这段和弦进行可以一直循环。
- 卡农进行。即C-G-Am-Em-F-C-Dm-G。可将进行分为C-G-Am-Em，以及F-C-Dm-G两部分。第一部分C-G是沿着五度圈走。在G感觉要解决到C时，故意不解决，而是来到近似于C的Am。在Am后通过小三作小调味道的展开，沿五度圈进行到Em。接下来进入第二部分。首先从Em到F。这结束了小调的感觉，回到大调，并且没有立即回到完全的主和弦，而是到下属的F。F到C又是五度圈。接着，我们想要以下属-属的感觉结尾。所以先来到下属功能的Dm。这里没有来到F是因为级进听起来更丝滑，并且F前面出现过了。然后最后Dm-G进行到属和弦。
- F-G-Am-Am进行。打破常规的和弦开头。其实就是从中间开始，直接给一个下属-属-主的感觉。
- Dm-Em-F-G进行。营造期待感。通过Dm，F一直停留在下属区域。中间塞个Em是为了保持级进营造抬升的期待感。最后来到属和弦G。

# 2. 和弦转位
- 转位三和弦在通奏低音中有四个音。一般在低音声部将root重复一下。这是因为只要低音是根音，听感就是原位。这样相当于给予转位原位的听感。反过来讲，也可以说是通过转位改变原位的听感。转位的性质主要由最低音影响。
- 原位，第一转位，第二转位听感上稳定性逐渐下降。可以通过转位改变每个和弦的听感。
- 可以将和弦低音的横向进行通过转位改成浮动较小的形式，这样使旋律更加稳定。反过来改成浮动较大的形式，旋律就更加活跃。
- 可以用七和弦衔接通奏低音的三和弦。例如从C进行到Am。Bass从C进行到A。如果过中间加入一个七和弦转位，使得进行成为C-Cmaj7/B-Am，那么衔接将更加顺畅。有时将Cmaj7/B简记为C/B，代表C的三和弦下面加一个B的bass。
