

# 2. 二音对一音
- 重拍横向之间以级进为主，跳进为辅。重拍跳进后必须反向级进补偿。
- 重拍横向之间类似一音对一音，避免平行移动，
- 重拍纵向必须与主音协和。当然，不一定完全协和。只有首尾要求完全协和。其中，结尾要求更加严格，只能纯一或者八度。（因为纯五度的终止感不如纯一或者八度。）
- 弱拍可以和主音不协和。不协和时，必须处在前后两个重音之间，被“包裹”住。称为经过音。

# 3. 三音对一音
- 重拍必须协和。并且遵循二音对一音的横向律动规律，以及平行移动之类的禁忌。
- 连续两次跳进是允许的。前提是跳进后又立即调回来。这称为修饰音，要求与两边的音形成5-3-5度或6-3-6度关系。
- 不协和音是允许的。除了经过音作为不协和音，可以引入第二种不协和音。要求二度级进到不协和音后又反向对称地二度级进回来。这称为不协和邻音。如同给协和的和弦井上添花，或者回旋镖。
- 开头和结尾同样和二音对一音一样。不过结尾最好从以主旋律相反的方向级进首尾，形成从两侧收束到中间的感觉。
