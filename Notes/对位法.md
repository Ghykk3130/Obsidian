

# 2. 二音对一音
- 重拍横向之间以级进为主，跳进为辅。重拍跳进后必须反向级进补偿。
- 重拍横向之间类似一音对一音，避免平行移动，
- 重拍纵向必须与主音协和。当然，不一定完全协和。只有首尾要求完全协和。其中，结尾要求更加严格，只能纯一或者八度。（因为纯五度的终止感不如纯一或者八度。）
- 弱拍可以和主音不协和。不协和时，必须处在前后两个重音之间，被“包裹”住。称为经过音。

# 3. 三音对一音
- 重拍必须协和。并且遵循二音对一音的横向律动规律，以及平行移动之类的禁忌。
- 连续两次跳进是允许的。前提是跳进后又立即调回来。这称为修饰音，要求与两边的音形成5-3-5度或6-3-6度关系。
- 不协和音是允许的。除了经过音作为不协和音，可以引入第二种不协和音。要求二度级进到不协和音后又反向对称地二度级进回来。这称为不协和邻音。如同给协和的和弦井上添花，或者回旋镖。
- 开头和结尾同样和二音对一音一样。不过结尾最好从以主旋律相反的方向级进首尾，形成从两侧收束到中间的感觉。

# 4. 延留音
- 指将对位的音延后出现。例如一音对一音时，将对位音整体后移两拍。和主旋律形成交错的感觉。延留音的基本结构是，现在上一个小节中间出现，和上一个小节的cantus firmus构成协和。这称为准备。然后延续到下一个小节，一般和下一个小节的cantus firmus不协和。然后停住。之后在下一个小节中间解决到一个和下一个小节cantus firmus协和的音。同时这个音也是下一个延留的准备。
- 2-3延留，9-10延留比较好，7-8延留不和谐。  延留的协和应该和它之前的主音的协和。所以延留同样应该避免两个完全平行。
- 结尾如果是上方对位，应该用7-6延留。下方对位则用2-3延留。为了这种好的结尾，有时候可以倒着写，先写结尾。

# 5. 华彩对位

- 华彩对位指前面各种对位大杂烩写一起。一般cantus firmus还是全音符，然后4/4拍。
- 延留音在华彩对位中的装饰：可以在一个延留音和它的解决之间，加一个音。这个音一般就是重复延留音，或者解决音，或者和延留音，解决音构成和弦，或者向上的一个好听的逃逸的音。当然，也可以在前面加延留音和解决音之间加两个音。一般是这两个音和解决之间构成不协和邻音，或者经过音。
![[Pasted image 20260802143514.png|centering|500]]
- 八分音符填充：例如下图，从第一排3度突然跳进到第三拍的6度，中间的弱拍可以用两个八分音符填充。这两个八分音符相当于某种“经过音”。值得注意的是 i) 八分音符填充只能发生在弱拍。ii) 八分音符和它们前后的两个音符这整体四个音必须构成四度。这样一来，这四个音就全部是二度级进，非常丝滑。

- 重拍的音可以用附点延长。
![[Pasted image 20260802144454.png|centering|500]]
-    Rhythmic arc：当节奏出现变化时，应当循序渐进，而不应该像第一行那样突然加快。第二行显然是更好的。普遍来说，rhythmic arc就是指这样一种循序渐进的过程：慢-快-慢-快-慢。中间的慢可以这样理解：如同过山车到顶部要停住，然后接下来需要蓄势冲下去。
![[Pasted image 20260802144851.png|centering|500]]
- 华彩对位可以把cantus firmus拆成一二，二三小节的小部分，每个小部分应该先写一个一音对一音的骨架，然后改成延留音。然后再在延留音上加装饰。

一些技巧：
- 想要顺利地衔接，中间最好放分解和弦。
- 想不出旋律时试试分解和弦，把已有的旋律转位。
- 变奏方法：把旋律移位，装饰，改变节奏。
- 导音是当前调式中，比主音低半度的音。具有强烈的解决到主音的倾向，可以用作结尾前。
- 两个音重复，中间可以加一个不协和邻音来打破这种重复。
