# 1. 一音对一音
- 同向平行的3，6度是合法的。通向平行的完全协和音则是非法的。

# 2. 二音对一音
- 重拍横向之间以级进为主，跳进为辅。重拍跳进后必须反向级进补偿。
- 重拍横向之间类似一音对一音，避免平行移动，
- 重拍纵向必须与主音协和。当然，不一定完全协和。只有首尾要求完全协和。其中，结尾要求更加严格，只能纯一或者八度。（因为纯五度的终止感不如纯一或者八度。）
- 弱拍可以和主音不协和。不协和时，必须处在前后两个重音之间，被“包裹”住。称为经过音。

# 3. 三音对一音
- 重拍必须协和。并且遵循二音对一音的横向律动规律，以及平行移动之类的禁忌。
- 连续两次跳进是允许的。前提是跳进后又立即调回来。这称为修饰音，要求与两边的音形成5-3-5度或6-3-6度关系。
- 不协和音是允许的。除了经过音作为不协和音，可以引入第二种不协和音。要求二度级进到不协和音后又反向对称地二度级进回来。这称为不协和邻音。如同给协和的和弦井上添花，或者回旋镖。
- 开头和结尾同样和二音对一音一样。不过结尾最好从以主旋律相反的方向级进首尾，形成从两侧收束到中间的感觉。

# 4. 延留音
- 指将对位的音延后出现。例如一音对一音时，将对位音整体后移两拍。和主旋律形成交错的感觉。延留音的基本结构是，现在上一个小节中间出现，和上一个小节的cantus firmus构成协和。这称为准备。然后延续到下一个小节，一般和下一个小节的cantus firmus不协和。然后停住。之后在下一个小节中间解决到一个和下一个小节cantus firmus协和的音。同时这个音也是下一个延留的准备。
- 2-3延留，9-10延留比较好，7-8延留不和谐。  延留的协和应该和它之前的主音的协和。所以延留同样应该避免两个完全平行。
- 如果是上方对位，结尾的前一小节应该用7-6延留。下方对位则用2-3延留。结尾处应该保持1度或八度。为了这种好的结尾，有时候可以倒着写，先写结尾。

# 5. 华彩对位

- 华彩对位指前面各种对位大杂烩写一起。一般cantus firmus还是全音符，然后4/4拍。
- 延留音在华彩对位中的装饰：可以在一个延留音和它的解决之间，加一个音。这个音一般就是重复延留音，或者解决音，或者和延留音，解决音构成和弦，或者向上的一个好听的逃逸的音。当然，也可以在前面加延留音和解决音之间加两个音。一般是这两个音和解决之间构成不协和邻音，或者经过音。
![[Pasted image 20260802143514.png|centering|500]]
- 八分音符填充：例如下图，从第一排3度突然跳进到第三拍的6度，中间的弱拍可以用两个八分音符填充。这两个八分音符相当于某种“经过音”。值得注意的是 i) 八分音符填充只能发生在弱拍。ii) 八分音符和它们前后的两个音符这整体四个音必须构成四度。这样一来，这四个音就全部是二度级进，非常丝滑。

- 重拍的音可以用附点延长。

-    Rhythmic arc：当节奏出现变化时，应当循序渐进，而不应该像第一行那样突然加快。第二行显然是更好的。普遍来说，rhythmic arc就是指这样一种循序渐进的过程：慢-快-慢-快-慢。中间的慢可以这样理解：如同过山车到顶部要停住，然后接下来需要蓄势冲下去。

# 6. 复对位写作
- 八度复对位，指创作一条对位，然后这条对位转位后仍然可以和cantus firmus对位。根据转为的表格，由于2,7度转为前后都不协和，5,4度转位后其中一个不协和。所以进行复对位写作时，暂时将5度当作不协和的。并且上方对位开头和结尾必须构成1度。因为1度转位成8度还是可以完美地构成开头和结尾。这样只需要正常写作，就可以作出复对位。
- 如前所述，将5度当作不协和。那么5度出现为不协和邻音就是完全可以接受的。 
![[Pasted image 20260802153303.png|centering|500]]
- 十度复对位，指创作一条对位，然后这条对位根据十度转位可以和cantus firmus对位。先来研究什么是十度转为。回忆起八度转为，需要input和output度数相加为8+1=9。加一这是因为音程度数的计算会计开头结尾，所以两个音程中间连接的部分计重了一次。类似地，十度转为就需要input和output度数相加为10+1=11。于是可以考虑各个音程和它的转位。我们发现，不协和转位后还是不协和。不完美协和转位后是完美协和。 所以写作时只需要将所有协和音当作完美协和即可。并且上方对位开头结尾必须是3度。因为3度转位后是8度，构成协和的开头结尾。
- 由于十度复对位中，所有协和都是完全协和，所以在两个强拍之间构成平行关系就都是完全协和音的平行。这是非法的。所以不能出现强拍之间的平行移动。
- 斜向进行由于会出现横向两个音是一样的情况，所以也是非法的。但是可以通过延留来斜向进行。 
- 十二度复对位。 类似地，需要input和output度数相加为12+1=13。类似地，只需要将6度当作不协和，正常写作即可。 上方对位开头结尾必须5度。
- 此外，需要注意，十二度复对位不应该在上方对位使用6-5延留。因为这样一来，转为后变成7-8延留。

# 7. 三声部对位
- 三声部对位。上方纵向出现两个音互为八度是非法的。这被视为一种削弱。但是下方则合法。因为在下方本身就有削弱的感觉。

- 数字低音记法：只写最下方的音，然后在这个音下面从上到下，从大到小，标记和这个音构成和弦的音的音程。会在都在上方或者下方的基础上，模掉八度，所以一个数字低音可以代表很多和弦。

- 三声部对位中，上方两个声部和声构成四度是合法的。这被当作一个不完全协和看待。这是因为四度本身听感是协和的，它被认为不协和是因为不够稳定。但是对位声部不得和cantus firmus构成不协和。65和弦是禁止的。因为一度本身听感就是不协和的。

- 从低音开始，使用距离低音协和的3，5，6，8度写两个音，可以写出如下和弦。其中65和弦是不协和的。因为高音和此高音相差仅1度。其它是协和的。我们将高音和此高音相差4度认为是协和。

![[Pasted image 20260804011534.png|centering|500]]


- 53，63和弦是最和谐的，因为其中任意两个音之间协和。当然，四度在此处被当成协和了。它们被称为完整三和弦。83，85，86被称为不完整三和弦。

- 二声部对位时，结尾公式一般是结尾前一小节，从该调的二级音通过中间过渡到一级音。或者从七级音上升到一级。这两种一种上升，一种下降。当然，不一定高音就只能上升来结尾。也可以下降的。
![[Pasted image 20260804004922.png|centering|500]]
- 三声部对位的结尾公式1：第一种方式是在cantus firmus下对位。三个声部都要收尾到这个调的主音。其中两个声部必须以二声部的那两个方式结尾。其中一个是7级音，另一个是2级音。那么现在需要构造第三个声部，它同样结尾到主音，并且和2级音，7级音协和。那就只能是5级音。这就是除了二声部对位的两个结尾公式外的第三个结尾公式。如图，可以选择一个53和弦。注意到这里低音和次低音声部是direct motion （direct motion指方向一样。完全平行只是direct motion的一种。），都是向下动。这一般是非法的，只有结尾才允许。因为结尾很难避免direct motion。
![[Pasted image 20260804005551.png|centering|500]]
- 三声部对位的结尾公式2：第二种方式是在cantus firmus 和高音声部之间对位。高音声部和低音声部各自用7-1或者2-1结尾。那么在结尾的准备小节，我们可以用63和弦填一个和7级音，2级音都协和的4级音。然后结尾落在3级或者5级音上。
![[Pasted image 20260804010519.png|centering|500]]
- 两个声部的短暂平行进行在三声部写作中被允许。但是此时第三个声部必须与这两个声部呈相反方向运动。
- 低音声部可以随便跳进。高音和此高音就不能跳进太频繁，不然突兀。

# 8. 四声部对位
- 四声部从高到低为soprano, alto, tenor, bass。
- 四声部1-1对位，每小节都必须三个声部完整三和弦。第四个声部一般选择和其中一个保持八度。不然很容易不协和。
- 平行八度只需要在两个声部之间避免。也就是说，soprano和tenor在这小节八度，下小节分开，然后alto和bass在下小节八度，这就不算八度平行。只需要标出每次纵向的八度在哪两个声部之间，然后保证这两个声部每小节不一样就可以了。
- 类似地，同样要避免两个声部之间的平行五度。注意，根据定义，平行是指必须纵向移动。如果完全一摸一样地亮小节重复，就不算平行，而应该看作一种特殊的手法，用来强调。最怕的就是动了，但又没完全动。
- 低音和弦：以C作为根音，C-E-G这个53和弦被称为原位。E-G-C这个63和弦相当于原位的cyclic permutation，被称为第一转位。G-C-E这个64和弦相当于再在循环群里面cyclic permutation一次，被称为第二转位。我们必须认为，在低音和弦体系中，这三个和弦都是以原位的根音C为”中心“的。其中，原位最为稳定，第一转为较轻，适合连接，第三转为最不稳定，不是很和谐。
![[Pasted image 20260804023311.png|centering|500]]
 
- 当然，可以以任意音作为根音，构造其原位，第一转位，第二转位和弦。我们用罗马数字标记根音的音级来代表这些和弦。大和弦用大写，小和弦用小写，减和弦在右上角写个圆圈。这个根音是在当前调中衡量的。比如在a小调中，实际上I和弦的根音是A。
![[Pasted image 20260804023713.png|centering|500]]
- 在罗马数字记法中，在罗马数字右上方写6表示第一转位，在右上方写6，右下方写4表示第二转位，不写是原位。
- 根据和弦写出罗马数字记法的方法：先找出和弦三个音，然后任意排列这三个音，直到凑出一个53和弦，那么53和弦的最低音就是根音。
- 第三转位在严格对位中是禁止的。
- 四声部对位时，不要重复6/3和弦的根音。
- 观察Mozart的结尾，把想强调的7-1结尾放在soprano和bass，能使得整个结尾有这个倾向。所以以后想强调什么，可以往soprano和bass放。因为四声部对位，这两个声部是最重要的。中间被包着的声部要弱一些。想想就知道，中间的alto和tenor被外面两个声部包着，就没有运动空间，只能一直重复。

# 9. 键盘体三和弦
- 琴键体三和弦指在bass上方为其编排三和弦。左手弹bass，右手在高音声部配一个三和弦。

# 一些技巧：
- 想要顺利地衔接，中间最好放分解和弦。
- 想不出旋律时试试分解和弦，把已有的旋律转位。
- 变奏方法：把旋律移位，装饰，改变节奏。
- 导音是当前调式中，比主音低半度的音。具有强烈的解决到主音的倾向，可以用作结尾前。
- 两个音重复，中间可以加一个不协和邻音来打破这种重复。
- 一般一些音程关系转位后被认为是同样的东西。常见的音乐思维。
- 看东西要看骨架。
